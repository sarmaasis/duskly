# Roadmap

This roadmap is directional, not a promise of delivery dates.

## v0.1

- [x] Monorepo with API and web Workers.
- [x] Email OTP authentication.
- [x] D1, KV, R2, Queues, Cron, and Durable Object scheduling path.
- [x] Core social account connection and publishing pipeline.
- [ ] Harden OAuth diagnostics for Meta/Instagram edge cases.
- [ ] Expand adapter test coverage for every network.
- [ ] Improve self-host deployment docs and troubleshooting.

## Later

- Team/workspace administration improvements.
- More publish targets and richer media handling.
- Import/export tools for self-hosted instances.
