# Support

## Community Support

Use GitHub Issues for reproducible bugs and GitHub Discussions for questions, setup help, and ideas.

Before opening an issue, please include:

- Duskly version or commit SHA.
- Self-hosted or Duskly Cloud.
- Browser/runtime and Cloudflare Worker logs when relevant.
- Steps to reproduce.

## Security

Do not post secrets, tokens, database dumps, or vulnerability details publicly. See `SECURITY.md`.

## Commercial Support

Duskly Cloud users can use the contact path published on `duskly.site`.
