# Contributing

1. Fork and branch from `main` (`feat/…`, `fix/…`).
2. `pnpm install`
3. Sign the DCO by using `Signed-off-by` on commits (`git commit -s`).
4. Open a PR. CI must pass.

## Rules

- API changes need a route test.
- Do not commit secrets or `.dev.vars`.
- UI: SL Design System density; primary buttons use `--color-cta`.
- One concern per PR.
